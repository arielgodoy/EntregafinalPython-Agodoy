# Paracopilot

Antes de realizar cambios:

1. Aplicar las reglas globales definidas en:
   .github/copilot-instructions.md

2. Consultar:
   COPILOT/INDICE.md

3. Leer SOLO la documentación especializada relacionada con la tarea actual.

4. NO leer toda la carpeta /COPILOT/ por defecto.

5. Para código vendor/theme:
   consultar COPILOT/REGLAS_CODIGO_VENDOR.md

6. Regla i18n:
   todo texto visible nuevo o modificado debe respetar el sistema data-key / static/lang existente.

7. Si una instrucción especializada contradice una regla global, detenerse e informar antes de modificar.
